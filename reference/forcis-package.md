# forcis: Handle the FORCIS Foraminifera Database

Provides an interface to the 'FORCIS' database (Chaabane et al. (2024)
[doi:10.5281/zenodo.7390791](https://doi.org/10.5281/zenodo.7390791) )
on global foraminifera distribution. This package allows to download and
to handle 'FORCIS' data. It is part of the FRB-CESAB working group
FORCIS.
<https://www.fondationbiodiversite.fr/en/the-frb-in-action/programs-and-projects/le-cesab/forcis/>.
